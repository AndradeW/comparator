# AGENTS.md

Small Go HTTP service that compares two HTTP responses (status, headers, JSON bodies). Module `comparator` (Go 1.26, dep: testify; dev tool: golangci-lint).

## Commands

- Run server: `go run ./cmd` (default port `8080`)
- Test: `go test ./...`; vet: `go vet ./...`
- Lint: `golangci-lint run ./...` (config `.golangci.yml`; v2 format)
- Makefile targets: `make build|run|test|vet|lint|fmt`
- CI: `.github/workflows/ci.yml` (build/vet/test + golangci-lint on push to `master` and PRs); frontend deploy is `.github/workflows/pages.yml`.

## Architecture

- Entrypoint `cmd/main.go` wires `httpclient` → `comparator.Service` → `api.Handler`, mounted by `internal/routes`. Middleware order: `requestlog.Middleware(cors.Middleware(server))`.
- `internal/requestlog` generates (or respects `X-Request-ID`), exposes it in the response header and logs structured request start/end (method, path, status, duration).
- Single endpoint: `POST /compare`. Accepts `{request1, request2}` each with `{url, method, headers, params, body}` (see `internal/dtos`); responds with `{status_codes, headers, body_differences}`.
  - `body_differences` is an array of `{path, tipo, values}` (`tipo`: `object`/`array`/`string`/`number`/`boolean`/`null`/`mixed`/`missing`/`error`).
- Routing uses Go 1.22 method patterns (`"POST /compare"`).
- Interfaces are defined at the consumer: `api.Handler` takes a `comparatorService` interface, `comparator.Service` takes an `httpClient` interface (single method `Do`).
- Error handling uses typed errors (`comparator.ValidationError`, `comparator.UpstreamError`) mapped in the handler to 400 / 502 / 500.
- Code comments and TODOs are in Spanish; keep that convention when adding comments.
- Commits use Conventional Commits (`feat:`, `fix:`, `docs:`, ...). API changes live in `feature/*` branches, integrated by PR.

## Config (env vars)

- `PORT` (default `8080`), `HTTP_TIMEOUT` (default `10s`), `MAX_BODY_SIZE` (default `1 MiB`), `MAX_RESPONSE_SIZE` (default `10 MiB`), `CORS_ALLOWED_ORIGIN` (empty = CORS disabled) in `config`.
- `httpclient.HTTPClient` applies the timeout; the handler wraps `r.Body` with `http.MaxBytesReader`; upstream bodies are capped by `MAX_RESPONSE_SIZE`.

## Frontend

- Static (no build) in `frontend/`; `config.js` is gitignored and generated by CI from the `API_BASE_URL` GitHub variable.
- Live site: `https://andradew.github.io/comparator/`; API: Render. `CORS_ALLOWED_ORIGIN` must match the Pages origin.

## Gotchas

- `internal/comparator/urlcheck.go` blocks SSRF targets (private/loopback/link-local IPs) but resolves the host at validation time; DNS-rebinding beyond that is not handled.
- Method allowlist: GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS (default GET).
- JSON comparison supports objects, arrays and scalars as root (paths like `[0]`, `a[0].b`).
- `compareBodyValues`/`compareJSON`/`compareArray`/`compareResponses`/`makeRequest`/`validateURL` are unexported but unit-tested directly from `internal/comparator` package tests.
